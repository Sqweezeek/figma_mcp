# Apex Supply storefront and responsive design skill

- Editable Figma design: https://www.figma.com/design/5EYeTWB2tXnJaTIeEcgypF
- Website source: [`docs/`](docs/)
- Reusable AI skill: [`skills/responsive-storefront-design/`](skills/responsive-storefront-design/)

The website is a static responsive page. Its narrow-screen layout is implemented with CSS breakpoints in `docs/styles.css`.

## Publish the website with GitHub Pages

In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/docs`, then save. GitHub Pages will publish the website at:

https://sqweezeek.github.io/figma_mcp/
